日常操作使用 ribbon、工具栏、右键菜单和拖拽。命令面板负责打开视图和快速输入，并提供搜索索引恢复，不会重复卡片导航功能。

## Ribbon 与命令面板

Ribbon 操作 **打开 Card Workspace** 会打开视图：桌面端在左侧边栏打开，手机和平板上则作为主工作区中的页面打开。

| 命令 id | 名称 |
| --- | --- |
| `open-view` | 打开 Card Workspace 视图 |
| `quick-input` | 打开快速输入 |
| `show-folder-card-search-index-status` | 显示 Card Workspace 本地搜索索引生命周期状态 |
| `recover-folder-card-search-index` | 恢复 Card Workspace 本地搜索索引生命周期 |
| `rebuild-folder-card-search-index` | 从笔记重建 Card Workspace 本地搜索索引 |
| `clear-reset-folder-card-search-index` | 清除并重置 Card Workspace 本地搜索索引状态 |

**打开快速输入** 每次都会打开一个新草稿；在不支持快速输入的环境中不可用。可在其他应用中使用的全局快捷键可在[设置](./settings.md#快速输入)中配置。后四项命令是本地索引恢复工具。普通查询使用面板内的 **搜索笔记**，详见[浏览卡片](../guides/browsing-cards.md)。

## 工具栏

工具栏会根据当前来源提供 **新建**、**排序与分组**、批量模式、当前筛选计数与 **清除筛选**，以及搜索。

进入[双链来源](../guides/linked-notes.md)后，还会提供 **固定到当前笔记** / **恢复跟随当前笔记**，以及 **存为卡片盒…**。在手机上，当前来源及其筛选改为显示在 Obsidian 的页面标题栏中。

## 导航栏顶部

导航栏顶部从左到右依次提供 **全部展开** / **全部折叠**、显示 **筛选导航…** 输入框的搜索图标，以及打开[快速输入](../guides/quick-input-and-templates.md#快速输入)的纸飞机按钮。**折叠导航栏** 可让卡片占满整个面板宽度。

## 导航菜单

在导航栏的分区标题或条目上右键。在触屏上，可点按条目的菜单按钮或长按条目。

- **分区** — 折叠或展开、上移、下移，或隐藏该分区
- **文件夹** — 新建笔记、文件夹、白板、Excalidraw 文件或数据库；重命名、创建副本、移动、复制路径、系统定位、搜索、包含子文件夹、排序子文件夹、定位当前笔记所在文件夹、展开或折叠、更改图标、收藏、隐藏与删除
- **标签** — 筛选、新建带标签的笔记、复制、同步引用后重命名或删除、排序分区或子标签、展开或折叠、更改图标、收藏或隐藏
- **属性** — 选择可见 key、清除筛选、排序属性名或值、全部展开或折叠；隐藏 key；加入、移除或仅保留某个值筛选；更改图标
- **卡片盒** — 新建、打开、配置（含分组）、加入当前视角、恢复移出笔记、创建副本、重命名、更改图标、收藏或删除
- **模板** — 新建模板；对某个模板可编辑文件、重命名，更改其新建笔记文件夹、日期与时间格式或插入位置，更改图标或删除
- **收藏** — 打开、排序、更改图标、移除或清空

双链标题使用通用的折叠和分区顺序操作；两个方向条目直接激活，不提供额外右键菜单。

## 卡片与批量菜单

右键卡片（触屏上点按其菜单按钮）可以选择打开位置；复制、移动、重命名或删除；管理收藏和卡片盒成员；更改 **背景颜色** 或图标；Markdown 卡片还可以复制内容、添加或删除标签，以及添加或删除属性。模板存储文件夹中的 Markdown 文件还提供 **设置为模板**。在手机和平板上，卡片菜单会为你刚才编辑的笔记增加插入和复制操作，详见[手机与平板](../guides/mobile.md#插入与复制卡片内容)。具体工作流与删除行为见[写作与整理](../guides/writing-and-organizing.md)。

打开 **批量** 后，工具栏提供全选、清除选择、移动、批量标签操作、批量属性操作、加入或移出卡片盒、背景颜色、删除和合并。批量属性操作可统一设置或移除 Markdown 笔记的属性，详见[写作与整理](../guides/writing-and-organizing.md#批量属性操作)。Shift+点击可连选；合并至少需要两篇 Markdown。把已选中的卡片拖到导航条目上时，操作会作用于全部所选卡片。
