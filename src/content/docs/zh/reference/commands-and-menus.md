title: 命令与菜单
description: Card Workspace 的命令面板命令、ribbon 以及右键菜单。
---

日常操作使用 ribbon、右键菜单和拖拽。命令面板用于打开视图，以及搜索索引的恢复 — 不是用来浏览卡片的。

## Ribbon

Ribbon 提示文字为 **打开 Card Workspace**。它会在左侧边栏打开面板。

## 命令面板

| 命令 id | 名称 |
| --- | --- |
| `open-view` | 打开 Card Workspace 视图 |
| `show-folder-card-search-index-status` | 显示 Card Workspace 本地搜索索引生命周期状态 |
| `recover-folder-card-search-index` | 恢复 Card Workspace 本地搜索索引生命周期 |
| `rebuild-folder-card-search-index` | 从笔记重建 Card Workspace 本地搜索索引 |
| `clear-reset-folder-card-search-index` | 清除并重置 Card Workspace 本地搜索索引状态 |

后四条搜索索引命令是恢复工具，不能替代面板内的 **搜索笔记**。只在本地索引需要查看状态、恢复、重建或重置时使用。

## 导航栏菜单

在导航栏的分区标题或条目上右键。

- **新建** — 新建笔记、文件夹、白板或数据库；新建带此标签的笔记；**新建卡片盒…**；**将当前视图存为卡片盒…**
- **整理** — 重命名、创建副本、移动；复制库内路径或系统路径；在系统资源管理器中显示；在文件夹中查找；展开或折叠文件夹和标签树；包含子文件夹；将标签加入或移出筛选
- **卡片盒** — 打开或退出卡片盒；配置；加入当前视图；恢复已移出的笔记；创建副本、重命名或删除卡片盒
- **收藏** — 加入或取消收藏；在同一类型内上移或下移；清空收藏
- **危险操作** — 删除文件夹；删除卡片盒（笔记仍留在库中）

进入卡片盒后，标签条目的右键菜单会被隐藏。

## 卡片菜单

右键卡片可以：

- **打开** — 当前窗口、新标签页、右侧分栏或新窗口
- **整理** — 创建副本；移动；加入或取消收藏；加入或移出卡片盒
- **仅 Markdown** — 复制标题、复制内容、复制标题和内容；添加或移除标签
- **危险操作** — 重命名；删除

## 批量菜单

打开 **批量** 后，工具栏提供全选、清除选择、移动所选、为所选添加或移除标签、删除所选、合并所选。合并仅适用于 Markdown，且至少需要两篇笔记。
