Card Workspace 1.4.3 的设置页分为 **行为**、**外观** 和 **导航**。在 Obsidian 中打开 **设置 → Card Workspace** 即可调整。活动筛选、可见属性、导航展开状态、分区顺序、文件夹与导航排序、搜索历史、卡片盒、收藏、置顶和面板尺寸会在适用时被记住。隐藏的文件夹、隐藏的标签和分区可见性在导航分组中管理。

| 设置键 | 默认值 | 名称 | 分组 |
| --- | --- | --- | --- |
| `defaultCardOpenBehavior` | `smart` | 卡片默认打开方式 | 行为 |
| `locateLinkCardOnOpen` | `false` | 双链卡片点击定位 | 行为 |
| `dragInsertAction` | `ask` | 卡片拖拽插入行为 | 行为 |
| `enableHeadingDragInsert` | `false` | 启用章节拖拽插入 | 行为 |
| `newNoteTemplate` | `tags-frontmatter` | 新建笔记内容 | 行为 |
| `cardCornerRadius` | `rounded` | 卡片圆角 | 外观 |
| `previewLines` | `5`（最小 0，最大 8） | 预览行数 | 外观 |
| `backlinkSnippetCount` | `3` | 反链默认显示的引用片段数 | 外观 |
| `searchPreviewSnippetCount` | `2`（最小 1，最大 5） | 每张卡片预览最多显示的命中片段 | 外观 |
| `cardImageMode` | `right` | 卡片图片 | 外观 |
| `cardImageFit` | `cover` | 图片显示方式 | 外观 |
| `showNavItemCounts` | `false` | 在导航栏显示条目计数 | 外观 |
| `hoverPreviewWidth` | `600`（最小 320，最大 1600） | 卡片悬浮预览宽度 | 外观 |
| `hoverPreviewHeight` | `400`（最小 200，最大 1200） | 卡片悬浮预览高度 | 外观 |

界面跟随 Obsidian 语言：语言以 `zh` 开头时使用简体中文，否则使用英文。Obsidian 1.13 及更高版本可通过设置搜索找到这些选项，并使用原生确认弹窗。Obsidian 1.11.4 至 1.12 显示相同的设置，并使用插件自带的兼容弹窗。版本要求见[限制与隐私](./limits-and-privacy.md)。

## 卡片默认打开方式

- **当前窗格 / 当前标签页**（`smart`）— 默认
- **在新标签页中打开**（`new-tab`）
- **在右侧分栏打开**（`split-right`）
- **在新窗口中打开**（`new-window`）

这些选项影响直接点击卡片。卡片菜单中的明确打开位置始终可用，详见[写作与整理](../guides/writing-and-organizing.md)。

## 双链卡片点击定位

默认关闭。开启后，从[双链来源](../guides/linked-notes.md)打开 Markdown 卡片时，会跳到摘要对应的链接位置：反链定位到引用来源笔记的位置，带标题或块引用的出链定位到目标位置。双链来源中有搜索查询时，优先定位到搜索命中位置。

普通文件夹与卡片盒中的卡片不受此选项影响；没有可用位置时，仍按正常方式打开笔记。

启用 Remember Cursor Position 时，可能短暂显示旧位置后再回到链接位置；其他恢复光标插件的行为取决于其实现。跳转位置也可能成为笔记下一次打开时恢复的位置。

## 卡片拖拽插入行为

- **每次弹框确认**（`ask`）— 默认
- **插入 wikilink**（`wiki`）
- **插入嵌入链接**（`embed`）
- **插入卡片正文**（`content`）
- **插入卡片标题与正文**（`title-content`）

## 启用章节拖拽插入

默认关闭。开启后，拖入 Markdown 卡片时可以选择一个标题章节。拖放沿用当前的拖拽插入方式，并保留整篇笔记入口。章节内容包含其下级标题，并在下一个同级或更高级标题处停止；插入的 Markdown 按原文复制。详见[按章节插入](../guides/writing-and-organizing.md#按章节插入)。

## 新建笔记内容

- **带 tags 属性**（`tags-frontmatter`）— 默认
- **完全空白**（`blank`）

## 卡片圆角

- **紧凑**（`compact`）
- **柔和**（`medium`）
- **圆角**（`rounded`）— 默认

## 预览行数

每张 Markdown 卡片可以显示 0–8 行规范化摘要，默认值为 `5`。设为 **0** 会隐藏普通摘要，让卡片更紧凑；搜索命中片段仍会显示。详见[浏览卡片](../guides/browsing-cards.md)。

## 反链默认显示的引用片段数

选择反链卡片在展开其余引用前显示多少段上下文：

- **1**、**2** 或 **3** — 默认是 **3**
- **全部**（`all`）— 显示每一段引用上下文

每张卡片仍可展开或收起其余引用。详见[双链导航](../guides/linked-notes.md)。

## 每张卡片预览最多显示的命中片段

搜索时，每张卡片可以显示 1–5 个正文命中片段，默认值为 `2`。每个片段占两行，并使用与普通摘要相同的列表、任务、标题、代码和链接提示。详见[搜索](../guides/browsing-cards.md#搜索)。

## 卡片图片

- **关闭**（`off`）— 使用纯文字布局。
- **右侧缩略图**（`right`）— 默认；在摘要旁显示 88 × 88 CSS 像素的图片。
- **标题下方内联图片**（`inline`）— 在标题与摘要之间显示横跨卡片正文、固定高度为 160 CSS 像素的图片。

卡片图片从 1.3.4 开始提供。新安装及升级前未保存图片偏好的用户默认使用 **右侧缩略图**；已明确保存的选择会保留。Markdown 卡片使用笔记正文中第一张受支持的本地嵌入图片，没有此类图片的笔记保持普通文字布局。支持的引用与加载行为见[卡片图片](../guides/browsing-cards.md#卡片图片)。

## 图片显示方式

- **完整显示**（`contain`）— 保留整张图片，周围可能留有空白。
- **裁切铺满**（`cover`）— 默认；铺满图片区域，超出部分会被裁切。

此选项适用于两种图片布局。**卡片图片** 为 **关闭** 时，这项设置会隐藏。切换布局或显示方式会复用缓存缩略图，不会重新生成。

## 在导航栏显示条目计数

在导航条目旁显示计数。文件夹计数跟随“包含子文件夹”，标签计数包含子标签，属性计数描述当前未筛选来源。默认关闭。

导航分区顺序通过各分区标题的右键菜单调整，不在设置页中。详见[导航](../guides/navigation.md)。

## 卡片悬浮预览尺寸

- **卡片悬浮预览宽度** — 320–1600 像素，步进为 10，默认 `600`。
- **卡片悬浮预览高度** — 200–1200 像素，步进为 10，默认 `400`。

尺寸适用于从卡片打开的页面预览，并会随窗口缩小。需要启用 Obsidian 核心插件 **页面预览**。详见[悬停预览与编辑器同步](../guides/browsing-cards.md#悬停预览与编辑器同步)。

## 导航可见性

导航分组只隐藏导航列中的条目。卡片、搜索、筛选和已有收藏仍然可用。

- **显示收藏**、**显示文件夹**、**显示标签**、**显示属性**、**显示卡片盒**、**显示链接** — 默认开启。关闭某一项会把该分区写入 `hiddenNavSections`。
- **隐藏的文件夹** 和 **隐藏的标签** — 点击 **管理** 打开全库列表。可以搜索，隐藏或恢复匹配项，也可以全部恢复。被子项的父项隐藏时，需要先恢复父项。仓库里已经不存在的条目会保留在列表中，直到你恢复它们。

这些规则在所有 Card Workspace 视图之间共享，重启后仍然保留，并会跟随文件夹移动、文件夹重命名，以及在插件内进行的标签重命名。右键菜单可以隐藏单个文件夹、标签或分区；恢复入口在这个分组。详见[隐藏导航条目](../guides/navigation.md#隐藏导航条目)。
