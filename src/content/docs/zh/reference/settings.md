在 Obsidian 中打开 **设置 → Card Workspace**。从 1.5.3 开始，设置页是一个包含七个页面的列表；选择其中一项即可打开，点击 **返回** 回到列表：

1. [界面外观](#界面外观) — 字体、间距、卡片样式与颜色
2. [卡片与预览](#卡片与预览) — 文件类型、摘要、图片与悬浮预览
3. [导航栏](#导航栏) — 分区显示、条目计数与隐藏条目
4. [打开与拖拽](#打开与拖拽) — 点击打开、链接定位与编辑器插入
5. [新建与模板](#新建与模板) — 新建内容、保存位置与模板文件夹
6. [快速输入](#快速输入) — 保存规则、输入字段、窗口与快捷键
7. [默认图标](#默认图标) — 导航条目与各类文件卡片的图标

界面跟随 Obsidian 语言：语言以 `zh` 开头时使用简体中文，否则使用英文。Obsidian 1.13 及更高版本可通过设置搜索找到这些选项，并使用原生确认弹窗。Obsidian 1.11.4 至 1.12 显示相同的页面，并使用插件自带的兼容弹窗。版本要求见[限制与隐私](./limits-and-privacy.md)。

活动筛选、可见属性、导航展开状态、分区顺序、文件夹与导航排序、搜索历史、卡片盒、收藏、置顶和面板尺寸会在适用时被记住。显示偏好按设备分别保存，详见[设备本地设置](./limits-and-privacy.md#设备本地设置)。在手机和平板上，仅适用于桌面端的设置会隐藏。

## 界面外观

| 名称 | 设置键 | 默认值 | 分组 |
| --- | --- | --- | --- |
| 字体大小 | `uiFontSize` | `default` | 文字与间距 |
| 紧凑程度 | `uiDensity` | `default` | 文字与间距 |
| 卡片样式 | `cardStyle` | `default` | 卡片样式 |
| 卡片圆角 | `cardCornerRadius` | `rounded` | 卡片样式 |
| 默认卡片背景颜色 | `cardBackgroundColor` | `theme` | 卡片样式 |

- **字体大小** — **小**、**默认**、**大** 或 **特大**，以 Obsidian 界面字号为基准，作用于卡片、工具栏和导航栏。
- **紧凑程度** — **紧凑**、**默认** 或 **宽松**，调整卡片之间与卡片内部的间距，以及导航行和搜索框的高度。
- **卡片样式** — **默认卡片**、**极简边框**、**列表**、**扁平** 或 **左侧强调条**。
- **卡片圆角** — **紧凑**、**柔和** 或 **圆角**。使用 **列表** 样式时隐藏。
- **默认卡片背景颜色** — **跟随主题**，或八种随明暗主题适配的预设色（红、橙、黄、绿、青、蓝、紫、粉）。适用于未单独设置颜色的卡片。

详见[外观与图标](../guides/appearance.md)。

## 卡片与预览

| 名称 | 设置键 | 默认值 | 分组 |
| --- | --- | --- | --- |
| 显示文件类型 | `fileVisibility` | `supported` | 显示内容 |
| 预览行数 | `previewLines` | `5`（最小 0，最大 8） | 显示内容 |
| 反链默认显示的引用片段数 | `backlinkSnippetCount` | `3` | 引用与搜索 |
| 每张卡片预览最多显示的命中片段 | `searchPreviewSnippetCount` | `2`（最小 1，最大 5） | 引用与搜索 |
| 卡片图片 | `cardImageMode` | `right` | 图片 |
| 图片显示方式 | `cardImageFit` | `cover` | 图片 |
| 卡片悬浮预览宽度 | `hoverPreviewWidth` | `600`（最小 320，最大 1600） | 悬浮预览 |
| 卡片悬浮预览高度 | `hoverPreviewHeight` | `400`（最小 200，最大 1200） | 悬浮预览 |

### 显示文件类型

- **仅文档**（`documents`）— Markdown、Base、Canvas 和 Excalidraw
- **常规格式**（`supported`）— 默认；文档，以及 Obsidian 和已安装插件注册的格式
- **全部格式**（`all`）— 仓库中的所有文件；Obsidian 无法打开的格式会通过外部应用打开

适用于文件夹、卡片盒和双链来源。变更会注册文件类型的插件后，请刷新 Card Workspace。详见[文件类型](../guides/browsing-cards.md#文件类型)。

### 预览行数

每张 Markdown 卡片可以显示 0–8 行规范化摘要，默认值为 `5`。设为 **0** 会隐藏普通摘要，让卡片更紧凑；搜索命中片段仍会显示。详见[浏览卡片](../guides/browsing-cards.md)。

### 反链默认显示的引用片段数

选择反链卡片在展开其余引用前显示多少段上下文：

- **1**、**2** 或 **3** — 默认是 **3**
- **全部**（`all`）— 显示每一段引用上下文

每张卡片仍可展开或收起其余引用。详见[双链导航](../guides/linked-notes.md)。

### 每张卡片预览最多显示的命中片段

搜索时，每张卡片可以显示 1–5 个正文命中片段，默认值为 `2`。每个片段占两行，并使用与普通摘要相同的列表、任务、标题、代码和链接提示。详见[搜索](../guides/browsing-cards.md#搜索)。

### 卡片图片

- **关闭**（`off`）— 使用纯文字布局。
- **右侧缩略图**（`right`）— 默认；在摘要旁显示 88 × 88 CSS 像素的图片。
- **标题下方内联图片**（`inline`）— 在摘要上方显示横跨卡片正文、高度为 160 CSS 像素的图片。

Markdown 卡片使用笔记正文中第一张受支持的本地嵌入图片；图片文件使用自身的缩略图。没有此类图片的笔记保持普通文字布局。Canvas 和 Excalidraw 图形不受此设置影响。支持的格式与加载行为见[卡片图片](../guides/browsing-cards.md#卡片图片)。

**图片显示方式** 可选 **裁切铺满**（`cover`，默认）或 **完整显示**（`contain`）。此选项适用于两种图片布局；**卡片图片** 为 **关闭** 时会隐藏。切换布局或显示方式会复用缓存缩略图，不会重新生成。

### 卡片悬浮预览尺寸

- **卡片悬浮预览宽度** — 320–1600 像素，步进为 10，默认 `600`。
- **卡片悬浮预览高度** — 200–1200 像素，步进为 10，默认 `400`。

尺寸适用于从卡片打开的页面预览，并会随窗口缩小。需要启用 Obsidian 核心插件 **页面预览**。详见[悬停预览与编辑器同步](../guides/browsing-cards.md#悬停预览与编辑器同步)。

## 导航栏

| 名称 | 设置键 | 默认值 | 分组 |
| --- | --- | --- | --- |
| 显示收藏、显示文件夹、显示标签、显示属性、显示卡片盒、显示链接、显示模板 | `hiddenNavSections` | 全部显示 | 分区显示 |
| 在导航栏显示条目计数 | `showNavItemCounts` | `false` | 条目显示 |
| 隐藏的文件夹 | `hiddenFolderPaths` | 无 | 条目显示 |
| 隐藏的标签 | `hiddenTagPaths` | 无 | 条目显示 |

此页面只隐藏导航列中的条目。卡片、搜索、筛选和已有收藏仍然可用。

- **显示…** — 每个分区一个开关，默认开启。关闭某一项会把该分区写入 `hiddenNavSections`。
- **在导航栏显示条目计数** — 在导航条目旁显示计数。文件夹计数跟随“包含子文件夹”，标签计数包含子标签，属性计数描述当前未筛选来源。
- **隐藏的文件夹** 和 **隐藏的标签** — 点击 **管理** 打开全库列表。可以搜索，隐藏或恢复匹配项，也可以全部恢复。因父项隐藏的子项会提示你先恢复父项。仓库里已经不存在的条目会保留在列表中，直到你恢复它们。

这些规则在所有 Card Workspace 视图之间共享，重启后仍然保留，并会跟随文件夹移动、文件夹重命名，以及在插件内进行的标签重命名。右键菜单可以隐藏单个文件夹、标签或分区；恢复入口在这个页面。分区顺序通过各分区标题的右键菜单调整。详见[隐藏导航条目](../guides/navigation.md#隐藏导航条目)。

## 打开与拖拽

| 名称 | 设置键 | 默认值 | 分组 |
| --- | --- | --- | --- |
| 卡片默认打开方式 | `defaultCardOpenBehavior` | `smart` | 点击打开 |
| 双链卡片点击定位 | `locateLinkCardOnOpen` | `false` | 点击打开 |
| 卡片拖拽插入行为 | `dragInsertAction` | `ask` | 拖拽插入 |
| 启用章节拖拽插入 | `enableHeadingDragInsert` | `false` | 拖拽插入 |

### 卡片默认打开方式

- **当前窗格 / 当前标签页**（`smart`）— 默认
- **在新标签页中打开**（`new-tab`）
- **在右侧分栏打开**（`split-right`）
- **在新窗口中打开**（`new-window`）— 仅桌面端

这些选项影响直接点击卡片。卡片菜单中的明确打开位置始终可用，详见[写作与整理](../guides/writing-and-organizing.md)。

### 双链卡片点击定位

默认关闭。开启后，从[双链来源](../guides/linked-notes.md)打开 Markdown 卡片时，会跳到摘要对应的链接位置：反链定位到引用来源笔记的位置，带标题或块引用的出链定位到目标位置。双链来源中有搜索查询时，优先定位到搜索命中位置。

普通文件夹与卡片盒中的卡片不受此选项影响；没有可用位置时，仍按正常方式打开笔记。

启用 Remember Cursor Position 时，可能短暂显示旧位置后再回到链接位置；其他恢复光标插件的行为取决于其实现。跳转位置也可能成为笔记下一次打开时恢复的位置。

### 卡片拖拽插入行为

- **每次弹框确认**（`ask`）— 默认
- **插入 wiki link**（`wiki`）
- **插入嵌入 link**（`embed`）
- **插入卡片内容**（`content`）
- **插入卡片标题&内容**（`title-content`）

仅桌面端；在手机和平板上，卡片菜单直接提供各项操作。

### 启用章节拖拽插入

默认关闭。开启后，拖入 Markdown 卡片时可以选择一个标题章节。拖放沿用当前的拖拽插入方式，并保留整篇笔记入口。章节内容包含其下级标题，并在下一个同级或更高级标题处停止；插入的 Markdown 按原文复制。详见[按章节插入](../guides/writing-and-organizing.md#按章节插入)。

## 新建与模板

| 名称 | 设置键 | 默认值 | 分组 |
| --- | --- | --- | --- |
| 新建笔记内容 | `newNoteTemplate` | `blank` | 新建笔记 |
| 卡片盒新建笔记保存位置 | `boxNewNoteFolderPath` | 仓库根目录 | 新建笔记 |
| 模板存储文件夹 | `templateStorageFolder` | `Card Workspace Templates` | 模板文件 |

- **新建笔记内容** — 工具栏 **新建** 按钮写入新笔记的内容：**完全空白**（`blank`，默认）或 **带 tags 属性**（`tags-frontmatter`）。
- **卡片盒新建笔记保存位置** — 从卡片盒新建的笔记保存在此文件夹，并加入该卡片盒。留空或填写 `/` 表示仓库根目录。
- **模板存储文件夹** — 保存所有模板文件。选择文件夹后点击 **应用** 或按 Enter，现有模板会迁移到该文件夹，保留原文件名和内容。文件夹不存在时会自动创建；不会覆盖同名文件。

详见[快速输入与模板](../guides/quick-input-and-templates.md)。

## 快速输入

| 名称 | 设置键 | 默认值 | 分组 |
| --- | --- | --- | --- |
| 快速输入文件夹 | `quickInput.folderPath` | 仓库根目录 | 保存与追加 |
| 标题与已有笔记同名时 | `quickInput.duplicateTitle` | `ask` | 保存与追加 |
| 追加位置 | `quickInput.insertPosition` | `end` | 保存与追加 |
| 显示标题、显示文件夹选择、显示卡片盒选择、显示标签添加、显示属性添加 | `quickInputVisibility` | 全部开启 | 输入字段 |
| 快速输入窗口宽度 | `quickInputWidth` | `480`（最小 320，最大 1200） | 窗口外观 |
| 快速输入窗口高度 | `quickInputHeight` | `400`（最小 200，最大 800） | 窗口外观 |
| 快速输入边框颜色 | `quickInputColor` | `random` | 窗口外观 |
| 快速输入窗口圆角 | `quickInputCornerRadius` | `rounded` | 窗口外观 |
| 快速输入全局快捷键 | `quickInputGlobalShortcut` | 无 | 快捷键 |

- **快速输入文件夹** — 新笔记默认保存在此文件夹，草稿中可另选。不填写标题时，每次发送都会新建一篇独立笔记，文件名如 `quick-note 2026-10-17 14-30-05.md`。
- **标题与已有笔记同名时** — **每次询问**（`ask`，默认）、**追加到该笔记**（`append`）或 **新建笔记并在名称后加数字**（`number`）。追加只写入草稿正文，目标笔记保留自己的属性。
- **追加位置** — **正文开头（属性之后）**（`start`）或 **笔记末尾**（`end`，默认）。同名时总是加数字新建的情况下，此项隐藏。
- **输入字段** — 五个开关，作用于之后打开的草稿。隐藏入口不会关闭相应能力；**Ctrl+;** 仍可添加属性。
- **窗口宽度** 和 **窗口高度** — 每个新草稿的尺寸，单位为像素。拖拽调整只影响当前草稿。
- **边框颜色** — **随机**（每个新草稿使用一种不同的主题颜色）、**强调色**、**主题主背景**、**主题次背景**，或八种固定颜色之一。
- **窗口圆角** — **紧凑**、**柔和** 或 **圆角**。
- **快速输入全局快捷键** — 默认未设置。按下组合键或输入 Electron 快捷键格式（如 `Control+Shift+Q`），然后点击 **应用**；点击 **清除** 可移除。

窗口宽度、高度、边框颜色和全局快捷键仅适用于桌面端。无法使用快速输入时，此页面会隐藏。详见[快速输入](../guides/quick-input-and-templates.md#快速输入)。

## 默认图标

此页面分为两组。**导航默认图标** 涵盖文件夹、标签、属性名、属性值、卡片盒、反链、出链和模板。**卡片默认图标** 涵盖 Markdown、Base、Canvas、Excalidraw、图片、PDF、音频、视频和其他文件卡片。

点击某个类别的按钮，可选择 Lucide 图标、emoji 或 **无图标**。已自定义的类别旁有重置按钮，可恢复其内置图标。直接在条目或卡片上选择的图标优先于这些默认图标。默认图标保存在 `iconDefaults` 中。详见[自定义图标](../guides/appearance.md#自定义图标)。
