这一组回顾 1.0 系列建立的基本工作方式：在左侧边栏内选择来源、扫读卡片，把有用的视角保存起来。

本页预留 **1.0.0–1.0.5** 的范围。实际发布记录只有 **1.0.0、1.0.1、1.0.2**；没有 1.0.3–1.0.5 的版本标签或 Release，不为这些版本补写功能。下一组从实际发布的 [1.1.2](./1-1-2-to-1-1-6.md) 开始。

## 独立的双栏导航

1.0.0 提供插件自己的文件夹、标签与卡片盒导航，旁边是带标题和摘要的卡片流。窄侧边栏会切换到单栏，导航列可调整宽度；ribbon 和命令面板都可以打开工作区，无需依靠文件浏览器联动。

导航还提供可选计数、数量提示，以及文件夹和笔记的常用右键操作。使用方法见[导航](../guides/navigation.md)与[命令与菜单](../reference/commands-and-menus.md)。

## 保存主题集合与常用入口

卡片盒可以保存文件夹与标签视角，或手动加入、移出笔记，帮助收集散落在不同位置的内容。常用的文件夹、笔记、标签和卡片盒可以收藏到导航栏。

详见[卡片盒](../guides/card-boxes.md)与[收藏导航](../guides/navigation.md)。后续版本又加入了属性规则、分组和收藏混排。

## 搜索、创建与整理笔记

本地搜索、置顶与虚拟滚动组成日常扫读流程；这一阶段强化了搜索索引持久化、库根路径处理和标签筛选。新建笔记会在新标签页打开，批量合并提供目标配置与预览。

详见[浏览卡片](../guides/browsing-cards.md)与[写作与整理](../guides/writing-and-organizing.md)。
