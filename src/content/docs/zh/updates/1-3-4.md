当前文档对应 **Card Workspace 1.3.4**。这一版本在已有的文字摘要与任务进度之外，为 Markdown 卡片加入本地图片预览。

## 默认显示右侧缩略图

卡片使用笔记正文中第一张受支持的本地嵌入图片，默认启用 **右侧缩略图**，并使用 **裁切铺满**。新安装和升级前未保存图片偏好的用户会采用这些默认值；已明确保存的选择会保留。

打开 **设置 → Card Workspace → 卡片图片**，可改为 **标题下方内联图片** 或 **关闭**。右侧缩略图为 88 × 88 CSS 像素；标题下方图片横跨卡片正文，高度固定为 160 CSS 像素。选择 **图片显示方式 → 完整显示** 可保留整张图片，不做裁切。

引用示例见[卡片图片](../guides/browsing-cards.md#卡片图片)，两项新增偏好见[设置](../reference/settings.md#卡片图片)。设置页现有九项选项。

## 使用正文中的本地图片

支持 Wiki 嵌入与 Markdown 图片，附件可以位于当前浏览文件夹之外。支持的格式为静态 PNG、JPEG、WebP 和 BMP。文件夹、卡片盒及双链来源中的 Markdown 卡片都能显示图片；点击图片会打开这张卡片对应的笔记。

远程图片、frontmatter 封面字段、HTML 图片、嵌入笔记、SVG、AVIF、GIF 及动画 PNG/WebP 不显示。没有可解析的受支持图片引用时，卡片保留文字布局。已选中图片校验或生成失败时，不会继续尝试其他附件。

## 稳定加载与缩略图缓存

通过缓存元数据识别受支持的引用，且文件大小在限制内时，卡片会在加载前预留图片空间。加载完成后以 240ms 淡入，并遵循减少动态效果设置；后续失败时保留相同大小的不可用占位。多列仍按行对齐，每张卡片保留自己的高度。

图片只在浏览区域附近按需加载。首次生成缩略图会等待可见文字补齐与前台绘制；已有缓存可跨重启复用。修改布局、显示方式、预览行数或搜索词，不会重新生成缩略图。

图片处理与缓存都在本机完成。原图限制、缓存容量和回退行为见[图片限制与本地缓存](../reference/limits-and-privacy.md#图片限制与本地缓存)。
