---
title: 浏览卡片
description: 扫读卡片流、在本地搜索、排序，并把笔记置顶。
---

卡片流用来扫读：点击卡片打开笔记，继续滚动，并与编辑器保持同步。

## 卡片显示什么

每张卡片都有 **标题** 和摘要。Markdown 笔记有完整预览，并进入全文搜索索引。`.base`、`.canvas` 以及 `.excalidraw` / `.excalidraw.md` 卡片只显示标题和占位说明，而不是 Markdown 摘要。

含有勾选任务的 Markdown 笔记还会在底部显示任务状态：未完成任务的数量，或全部完成的图标。非 Markdown 卡片没有任务栏。

如果 Markdown 笔记顶部附近没有可预览的文本，卡片会显示 **顶部附近没有可预览的文本。** 摘要行数由 [设置](/card-workspace-site/zh/reference/settings/) 中的 **预览行数** 控制。

滚动采用虚拟化布局：只渲染当前可见的卡片，避免一次挂载完整列表。

## 悬停预览

将指针停在标题或摘要上，并按住 Obsidian **页面预览** 要求的修饰键（默认是 Ctrl 或 Cmd），即可预览笔记而不打开它。置顶、批量和更多操作控件不会触发预览。

## 双向同步

点击卡片可打开对应笔记。在编辑器中切换笔记时，对应卡片会自动选中。

## 搜索

工具栏的 **切换搜索**（**搜索笔记**）会在当前文件夹、「文件夹 + 标签」范围或卡片盒内做本地搜索。Markdown 卡片会直接高亮命中文字，并显示每篇笔记的命中次数。

- 查询为空时，显示当前范围内的全部卡片。
- 查询非空时，需等本地索引就绪。就绪前卡片流为空，并显示 **搜索当前不可用**。
- Markdown 的标题和正文会进入索引，frontmatter 不会。Base、Canvas 和 Excalidraw 卡片 **只按标题** 索引。
- 中文按单字和相邻两字匹配，可与英文混搜。拼音不会进入索引。

在文件夹上右键选择 **在文件夹中查找**，会选中该文件夹并聚焦这个搜索框。它不会打开 Obsidian 自带的搜索。

搜索索引的恢复命令见 [命令与菜单](/card-workspace-site/zh/reference/commands-and-menus/)。它们不是日常浏览的一部分。

## 排序

使用工具栏上的 **排序**。选项包括：

- 编辑时间（从新到旧）/ 编辑时间（从旧到新）
- 创建时间（从新到旧）/ 创建时间（从旧到新）
- 文件名（A 到 Z）/ 文件名（Z 到 A）

文件夹浏览使用全局排序。卡片盒使用 **该卡片盒自己的** 排序。

## 置顶

使用卡片上的 **固定笔记** / **取消固定**，把卡片留在流的顶部。置顶不会绕过搜索或标签筛选，只重排已经匹配的卡片。置顶卡片之间的相对顺序跟随卡片流顺序，而不是你置顶的先后顺序。文件夹置顶名单和卡片盒置顶名单是分开的。

## 标签筛选

工具栏上的 **标签**，或在 **标签** 分区中点击，用于筛选文件夹卡片流。选中多个标签时是 **AND**：笔记必须同时带有这些标签。父标签也会匹配其子标签。进入卡片盒后该筛选不可用 — 见 [卡片盒](/card-workspace-site/zh/guides/card-boxes/)。
