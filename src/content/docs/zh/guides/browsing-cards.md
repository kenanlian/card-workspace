卡片流用于快速扫读：阅读摘要、继续滚动，并在不丢失周围上下文的情况下打开值得关注的笔记。

## 卡片显示什么

每张卡片都有标题。Markdown 笔记还会显示可读摘要、全文搜索高亮，以及包含复选框任务时的任务进度。`.base`、`.canvas`、`.excalidraw` 和 `.excalidraw.md` 卡片显示标题与占位说明，并且只按标题搜索。

摘要保留标题、代码、链接文字、列表标记和任务复选框等轻量提示，方便区分内容结构；它不是完整的 Markdown 阅读视图。Wikilink 和 Markdown 链接会突出显示其文字，点击卡片仍然打开这张卡片对应的笔记。任务复选框用于预览状态，修改任务需要打开笔记。

包含任务的卡片会在底部显示 **已完成 / 总数**，例如 `2/5`，便于判断进度；没有任务的笔记不显示该进度。预览中的已完成与未完成任务使用对齐的复选框。

Markdown 顶部附近没有可预览内容时，卡片显示 **顶部附近没有可预览的文本。** 可在[设置](../reference/settings.md)中用 **预览行数** 控制摘要高度：0–8 行，默认 5。设为 **0** 会隐藏普通摘要；搜索有正文命中时仍会显示命中片段。

卡片流采用虚拟滚动，大型来源只渲染可见范围；摘要按需加载。切换文件夹和首次打开大型来源时，卡片内容会逐步补齐。

## 卡片图片

从 1.3.4 开始，Markdown 卡片可以显示笔记正文中第一张受支持的本地嵌入图片，默认使用 **右侧缩略图** 和 **裁切铺满**。在 **设置 → Card Workspace → 卡片图片** 中可切换为 **标题下方内联图片** 或 **关闭**；希望不裁切图片时，选择 **图片显示方式 → 完整显示**。布局与尺寸见[设置参考](../reference/settings.md#卡片图片)。

在笔记正文中使用 `![[Attachments/photo.jpg]]` 或 `![照片](../Attachments/photo.jpg)` 这样的嵌入。附件可以位于仓库中的其他位置，不必放在当前浏览的文件夹内。文件夹、卡片盒与双链来源中的 Markdown 卡片都支持图片。点击图片会打开这张卡片对应的笔记。

- 支持本地静态 PNG、JPEG（`.jpg` / `.jpeg`）、WebP 和 BMP。
- 选择第一张图片时，会跳过缺失引用和不支持的文件扩展名。远程 URL、frontmatter 封面字段、HTML 图片和嵌入笔记不作为图片来源；SVG、AVIF、GIF 及动画 PNG/WebP 不显示。
- 已选中图片超出限制或加载失败时，不会继续尝试同一笔记中的其他附件。没有可解析的受支持引用时，卡片保持普通文字布局。

缩略图只在可见行及前后各一行按需加载。首次生成会等待可见文字补齐，大图可能比摘要稍晚出现。确认受支持的引用和合适的文件大小后，卡片会在加载前预留图片区域；后续校验或加载失败时，保留相同大小的不可用占位。加载完成后，图片第一次出现时以 240ms 淡入；开启减少动态效果时直接显示。之后刷新同一张缩略图不会再次淡入。编辑笔记时，只要图片引用没有变化，当前缩略图会保留。多列仍按行对齐，每张卡片保留自己的高度。

缩略图缓存在本机，可跨重启复用。修改图片布局、显示方式、预览行数或搜索词不会重新生成缩略图。大小限制及环境不支持时的行为见[图片限制与本地缓存](../reference/limits-and-privacy.md#图片限制与本地缓存)。

## 悬停预览与编辑器同步

按住 Obsidian 的页面预览修饰键（默认 Ctrl 或 Cmd），悬停标题或摘要即可预览笔记。置顶、批量和更多操作按钮不会触发预览。启用核心插件 **页面预览** 后，可在[设置](../reference/settings.md#卡片悬浮预览尺寸)中调整 **卡片悬浮预览宽度** 和 **卡片悬浮预览高度**，默认 600 × 400 像素，并会随窗口缩小。

点击卡片会打开笔记；在编辑器中切换笔记时，对应卡片会被选中。[双链来源](./linked-notes.md)还会在没有固定时跟随活动笔记。

## 搜索

工具栏的 **切换搜索** 会打开 **搜索笔记**，搜索当前文件夹、卡片盒、出链或反链来源。Markdown 卡片会高亮命中文字，并保留每篇笔记的命中次数。

正文命中按原文顺序显示为独立片段，并使用与普通摘要相同的列表、任务、标题、代码和链接提示。每个片段占两行。[设置](../reference/settings.md#每张卡片预览最多显示的命中片段)决定一张卡片显示多少个片段：1–5 个，默认 2 个。重叠的上下文会合并；较短的命中行会带上后面的正文。点击片段，或在片段获得焦点时按 Enter 或 Space，会在笔记当前的编辑或阅读模式中打开该命中。

只有标题匹配时，标题会高亮，并保留开头摘要。清空搜索后恢复当前来源的摘要；双链来源的上下文规则见[双链导航](./linked-notes.md)。

**搜索历史** 在所有卡片视图之间记住最近 30 条查询。输入时最多列出 6 条匹配。可以删除单条记录，或选择 **清空历史**。收起搜索或清空查询时，会先记下当前文本。历史中没有匹配时不显示建议。

- 空查询显示应用于当前来源的浏览筛选后的结果。
- 非空查询会等待本地索引就绪；在此之前面板会提示搜索被阻塞。
- Markdown 标题和正文进入索引，frontmatter 不进入；其他受支持卡片类型只索引标题。
- 中文搜索使用单字和相邻双字，也支持中英文混合查询；不索引拼音。

本地索引会跨重启保留；仓库没有变化时会复用索引，避免重复重建和写入。首次索引仍需要时间。索引恢复工具见[命令与菜单](../reference/commands-and-menus.md)。

## 排序与分组

打开工具栏的 **排序与分组**。文件夹中的卡片可以按编辑时间、创建时间或文件名排序，并选择升序或降序。出链和反链还可以按 **引用次数** 排序，并且各自记住排序；两者默认都是引用次数从高到低。详见[双链导航](./linked-notes.md)。

文件夹来源共用一套全局分组。[卡片盒](./card-boxes.md)保留自己的排序和分组。分组维度包括：

- **文件夹** — 按笔记所在文件夹分组。
- **标签** — 按完整标签集合分组，而不是只取第一个标签。`#research` 与 `#research #draft` 属于不同组；同一集合的标签顺序不影响归组。
- **任务状态** — 分为 **有未完成**、**全部完成** 和 **无任务**。
- **属性** — 按已启用的 frontmatter 属性值分组，操作步骤见[属性筛选](./property-filters.md)。
- **卡片盒规则** — 仅在卡片盒中可用；匹配多条规则的笔记归入第一条匹配规则，没有规则匹配的手动成员进入 **手动添加** 组。

分组顺序可以采用默认序列、名称或卡片数量，并设置升降序。每个分组标题会显示分组维度、值与数量，可单独折叠；菜单也可以一次全部折叠或展开。滚动浏览较长的分组时，当前组标题会停留在卡片流顶部，直到该组滚出视野。

## 置顶

使用卡片上的 **置顶笔记** 或 **取消置顶**，让它在当前排列中优先显示。置顶不会绕过搜索或适用于当前来源的浏览筛选，只会重排已经匹配的卡片；启用分组时，置顶笔记仍留在所属组内，并排在组内前面。

文件夹与双链来源共用全局置顶；每个卡片盒拥有独立的置顶列表。

## 浏览筛选

标签和属性浏览筛选仅适用于文件夹来源。多个标签之间为 AND，父标签会包含子标签。属性筛选在同一属性内为 OR，不同属性之间为 AND。

在导航栏中启用非空标签筛选，会清除当前属性筛选；启用非空属性筛选，也会清除当前标签筛选。Ctrl/Cmd 加点击和 Space 可在同一种筛选内追加条件。要长期保留标签或属性视角，可以保存为[卡片盒成员规则](./card-boxes.md)。

卡片盒和双链来源都不会应用这两种浏览筛选。已有的文件夹标签或属性条件会在其中暂时停用；条件存在时，Card Workspace 会显示筛选已暂停的提示，返回文件夹后会恢复生效。卡片盒自身的成员规则仍可包含标签或属性条件。
