Card Workspace 是一款支持输入、汇集、整理和重构笔记的 [Obsidian](https://obsidian.md/) 插件，把笔记显示成一条可读的卡片流：桌面端位于编辑器旁的 **左侧边栏**，手机和平板则在主工作区打开。每张 Markdown 卡片都有标题和带有链接、列表与任务提示的轻量摘要，不必把一组笔记压缩成一串文件名。

卡片流的来源可以是文件夹、卡片盒，也可以是某篇笔记周围的出链或反链。本地搜索适用于每种来源；标签和属性筛选可以收窄文件夹和卡片盒。[导航](./navigation.md)会说明这些入口如何共存在一个紧凑的双栏面板中。

正文嵌入受支持图片的 Markdown 卡片会显示[本地图片预览](./browsing-cards.md#卡片图片)。图片、PDF、音频、视频、Canvas 和 Excalidraw 文件也能显示为卡片；Canvas 和 Excalidraw 会显示一张小图形。

点击卡片会打开笔记；在编辑器中切换笔记时，对应卡片也会被选中。卡片盒只汇集笔记，不会移动文件。需要重新整理时，把卡片拖到导航列中的文件夹、标签、属性值或卡片盒上即可。

## 四段式工作流

- **输入** — 用[快速输入](./quick-input-and-templates.md)随手记下想法，新建继承当前标签和属性的笔记，或从模板开始。
- **汇集** — 在文件夹和卡片盒中用标签和 frontmatter 属性浏览，或沿双链寻找笔记。
- **整理** — 排序、分组、置顶，再把有用的视角保存成[卡片盒](./card-boxes.md)；把卡片拖到导航条目上即可移动文件或添加标签。
- **重构** — 在编辑器旁打开上下文，或把卡片拖入正在写的笔记。

## 适合谁

Card Workspace 适合一边写作、一边扫读和收集笔记的人：研究主题、长期项目、阅读清单，以及任何跨越文件夹的工作。它提供直接操作，不引入另一套查询语言。

## 运行要求

- **桌面端、Android 和 iOS/iPadOS。** 移动端布局的差异见[手机与平板](./mobile.md)。
- **Obsidian 1.11.4 或更高版本。** 更早的 Obsidian 会停留在 Card Workspace 1.3.4。Obsidian 1.13 及更高版本还会提供设置搜索和原生确认弹窗。
- 界面跟随 Obsidian 语言：语言以 `zh` 开头时使用简体中文，否则使用英文。

接下来先[安装插件](./installation.md)，再进入[快速开始](./getting-started.md)。已有使用经验，可以查看 [1.4.4–1.5.3](../updates/1-4-4-to-1-5-3.md)，了解快速输入、模板、移动端支持、外观和拖放整理。
