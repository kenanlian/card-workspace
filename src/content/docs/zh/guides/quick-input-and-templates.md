Card Workspace 提供三种开始一篇笔记的方式：工具栏的 **新建** 按钮在当前视图中创建，**快速输入** 用来立刻记下一个想法，**模板** 则适合反复书写的笔记。

## 新建笔记

工具栏的 **新建** 会在当前文件夹（包括库根目录）中创建一篇名为 **未命名** 的笔记并打开。

- 选中的标签，以及生效的文本、数字或布尔属性筛选，会写入新笔记的 frontmatter。同一属性选中多个值时，使用导航顺序中的第一个值。
- 在[卡片盒](./card-boxes.md#在卡片盒中新建笔记)中，笔记保存在 **卡片盒新建笔记保存位置**（默认为库根目录），继承盒子当前的筛选，并加入该卡片盒。
- 在[双链来源](./linked-notes.md)中，笔记保存在上次浏览的文件夹，不带暂停的筛选。

新笔记默认完全空白。如果想以空的 `tags` 属性开头，可在 **设置 → Card Workspace → 新建与模板** 中修改 **新建笔记内容**。

## 快速输入

点击导航标题右侧的纸飞机按钮，或从命令面板运行 **打开快速输入**。每次打开都会新建一份空白草稿。

在桌面端，每份草稿都是一个带彩色边框的独立小窗口。可以同时打开多份草稿，主窗口最小化时也不影响。拖动顶部的三点手柄移动草稿，拖动边缘或四角调整大小。左下角的置顶按钮让该窗口保持在最前，每份新草稿默认开启。点击别处会保留草稿；**取消** 会丢弃草稿。

### 使用前准备

桌面端快速输入需要在 **设置 → 外观 → 窗口框架样式** 中选择 **Obsidian 框架** 或 **隐藏框架**。修改后请完全重启 Obsidian。使用系统原生框架时，快速输入不会打开，而是提示需要修改的设置；插件不会替你修改这项设置。

### 编写与发送

输入笔记正文；Enter 换行，**Ctrl/Cmd+Enter** 发送。输入法组合输入期间不会误发送。草稿还可以设置：

- **标题** — 可选，只决定文件名。留空时使用时间戳名称，例如 `quick-note 2026-10-17 14-30-05.md`。
- **文件夹** — 笔记的保存位置。文件夹建议会搜索仓库中的所有文件夹。
- **卡片盒** — 选择一个或多个卡片盒，发送时笔记会加入全部所选盒子。已有的成员关系不会被移除。
- **添加标签** 和 **添加属性** — 用 Obsidian 自带的属性编辑器编辑 frontmatter。即使按钮被隐藏，**Ctrl+;** 也能添加属性。完全留空的属性不会保存。

这五项默认全部显示。不需要的可以在 **设置 → Card Workspace → 快速输入 → 输入字段** 中隐藏；隐藏入口不会停用对应的快捷键。修改只影响之后打开的草稿。

发送成功后，草稿关闭并提示笔记的保存位置，但不会打开笔记。发送失败时，草稿保持原样，方便再次尝试。草稿只保存在内存中：通过操作系统关闭窗口、退出 Obsidian 或重启后都不会保留。

### 标题已存在时

**标题与已有笔记同名时** 决定标题与所选文件夹中的已有笔记相同时如何处理：

- **每次询问** — 默认；发送时选择，或取消后继续编辑
- **追加到该笔记** — 把草稿正文加入那篇笔记，笔记自己的属性保持不变，发送按钮显示为 **追加**
- **新建笔记并在名称后加数字** — 例如 `标题 1.md`

**追加位置** 可选正文开头（属性之后）或笔记末尾，默认为笔记末尾。

### 窗口与全局快捷键

在 **设置 → Card Workspace → 快速输入** 中，可以设置每份新草稿的宽度和高度（默认 480 × 400 像素）、圆角和边框颜色。**随机** 会选用一种与上一份草稿不同的主题颜色；也可以选择强调色、主题背景色或某一种固定颜色。

**快速输入全局快捷键** 默认留空。按下组合键，或输入 `Control+Shift+Q` 这样的 Electron 快捷键格式，然后点击 **应用**。这个快捷键可以从任意软件打开新草稿，不会把主窗口调到前面。组合无效或已被占用时，原有快捷键保持不变。**清除** 会移除它。

### 在手机和平板上

快速输入以 Obsidian 弹窗打开：手机上全屏，平板上居中。一次只有一份草稿。关闭已修改的草稿时需要确认。窗口大小、颜色和全局快捷键只适用于桌面端。

## 模板

导航中的 **模板** 分区列出你的模板，默认位于双链下方。

### 创建模板

1. 点击 **模板** 标题上的 **+** 按钮，或右键该标题并选择 **新建模板**。
2. 填写模板名称，以及用这个模板创建的笔记所保存的文件夹。模板名称只显示在导航和模板选择中。
3. 模板会打开供编辑，并选中其标题。替换这个标题：它会成为每篇由该模板创建的笔记的文件名。正文以一段简短的引导引用开头；请修改或删除它，因为它是真实的模板内容。

如果想使用已有的 Markdown 文件，或从其他设备同步过来的文件，可在 Obsidian 文件浏览器或 Card Workspace 卡片上右键，选择 **设置为模板**。这一项只对模板存储文件夹中尚未注册的文件显示。文件会保留原有名称和内容。

### 使用模板

在导航中点击模板。如果模板文件夹中没有与模板标题同名的笔记，会用完整模板新建一篇笔记。如果已经存在，会把模板正文插入那篇笔记，并保留它的属性和文字；模板菜单中的 **同名笔记插入位置** 可选正文开头或笔记末尾（默认）。笔记会以编辑模式打开，光标停在插入文字的末尾。

每次点击都会读取模板的最新版本，包括尚未保存的修改。

### 日期与时间

标题或正文中的 `{{date}}` 和 `{{time}}` 会插入当前日期和时间，格式使用模板菜单中的设置。如果想在某个位置使用其他格式，可写 `{{date:YYYY-MMMM-DD}}` 或 `{{time:HH:mm}}`，与 Obsidian 的“模板”插件一致。同一篇笔记中的所有变量使用同一时刻。文件名中不允许的字符会替换为 `-`，因此日期中的斜杠不会创建文件夹。

### 管理模板

模板菜单可以编辑模板文件、重命名模板、修改它的笔记文件夹或日期与时间格式，以及删除模板。**删除模板** 使用 Obsidian 的常规删除流程；取消删除时会保留模板。

所有模板文件都存放在 **设置 → Card Workspace → 新建与模板** 中的 **模板存储文件夹**，默认为 `Card Workspace Templates`。选择其他文件夹并点击 **应用**，会把所有模板移动过去，保留文件名和内容。文件夹不存在时会自动创建；如果有文件缺失或名称冲突，不会覆盖任何文件，移动也会停止。模板文件是普通的 Markdown 笔记，因此也会出现在卡片、搜索和 Obsidian 文件浏览器中。

快速输入不使用模板。
