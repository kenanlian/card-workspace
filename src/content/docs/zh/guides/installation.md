Card Workspace 可以直接在 Obsidian 的第三方插件市场中安装。如果需要特定版本，也可以从 GitHub Releases 手动安装。

## 运行要求

- 桌面版 Obsidian（不支持移动端）
- Obsidian **1.9.0** 或更高版本
- 插件界面跟随 Obsidian 语言（`zh*` → 简体中文，否则为英文）

## 从插件市场安装

1. 打开 Obsidian 的 **设置 → 第三方插件**。
2. 如已开启安全模式（Restricted mode / Safe mode），请先关闭。
3. 点击 **浏览**，搜索 **Card Workspace**。
4. 依次点击 **安装** 和 **启用**。

插件的[市场页面](https://community.obsidian.md/plugins/card-workspace)对应同一个条目，也可以从网页直接跳回 Obsidian 安装。

## 从 GitHub Releases 手动安装

需要安装当前版本以外的版本时使用这种方式。

1. 前往 [Releases](https://github.com/kenanlian/obsidian-card-workspace/releases) 页面下载所需版本。
2. 解压压缩包，并将 `main.js`、`manifest.json` 和 `styles.css` 复制到：

   `<vault>/.obsidian/plugins/card-workspace/`

3. 打开 Obsidian 的 **设置 → 第三方插件**。
4. 如已开启安全模式（Restricted mode / Safe mode），请先关闭。
5. 在已安装插件列表中启用 **Card Workspace**。
