点击、右键菜单、批量模式和拖拽覆盖了大多数日常操作。设置只改变默认点击和拖放行为，明确的菜单操作始终可用。

## 打开卡片

直接点击使用 **卡片默认打开方式**。默认会尽量复用未固定的根编辑器标签页，否则打开新标签页。其他选择是新标签页、右侧分栏或新窗口，详见[设置](../reference/settings.md)。

从[双链导航](./linked-notes.md)打开卡片时，可以把来源笔记固定在 Card Workspace 中，一边检查上下文一边继续写作。开启 **双链卡片点击定位** 后，打开卡片还会跳到摘要对应的引用或搜索命中位置，详见[设置](../reference/settings.md)。

## 拖入 Markdown 编辑器

把卡片拖到已打开的 Markdown 编辑器中的具体位置。默认行为是 **每次弹框确认**。不同卡片类型允许：

- Markdown — wikilink、嵌入、正文或标题与正文
- Base 和 Canvas — wikilink 或嵌入
- Excalidraw — 仅 wikilink

请求不支持的操作时，Obsidian 会显示 **此卡片类型不支持该拖拽插入操作。**

## 新建笔记与文件

工具栏 **创建笔记** 使用配置中的新建内容：默认为空的 `tags` 属性，也可以完全空白。文件名以 **未命名** 为基准。

从文件夹菜单可以在该文件夹中新建笔记、文件夹、白板或数据库。标签菜单可以在当前文件夹新建已经带有该标签的笔记。从卡片盒中使用文件夹新建操作时，会切回对应的文件夹来源。

## 导航与卡片菜单

导航菜单覆盖新建、重命名、创建副本、移动、复制路径、在系统资源管理器中显示、收藏、展开树、调整分区、筛选和[卡片盒](./card-boxes.md)操作。重命名或删除标签时，确认后会同步更新或移除笔记、活动筛选、收藏和卡片盒规则中的引用。

卡片菜单可以选择打开位置；复制、移动、重命名或删除文件；管理收藏和卡片盒成员；Markdown 卡片还可以复制内容或编辑标签。完整清单见[命令与菜单](../reference/commands-and-menus.md)。

复制 Markdown 内容时会跳过顶部 frontmatter，得到正文；文件副本仍保留原始文件内容。

## 批量模式

打开 **批量**，点击卡片即可切换选中；Shift+点击从上次选中的卡片开始连选。

- 全选或清除选择
- 移动所选笔记
- 添加或移除标签
- 批量设置或移除 Markdown 笔记的属性
- 加入卡片盒，或从当前卡片盒移出
- 删除所选笔记
- 合并所选 Markdown 笔记

合并至少需要两篇 Markdown。对话框可以设置标题、目标文件夹、来源顺序、分隔符、是否保留源笔记，并提供实时预览。只有第一篇来源笔记的 frontmatter 会保留在合并结果顶部；其他来源的 frontmatter 不会合并进去。

### 批量属性操作

在批量模式中选中 Markdown 笔记，点击工具栏的 **批量属性操作**。对话框会显示本次作用的笔记数量；可在一次操作中设置多个属性，并移除其他不再需要的属性。

- **设置属性**：填写属性名、类型和值，为所选笔记创建属性或覆盖已有值。例如，将一组笔记的 `status` 统一设为 `review`。
- **类型与值**：支持文本、列表、数字、复选框、日期和日期时间；列表项支持文本或数字，设置列表时会替换原有列表。
- **输入建议**：属性名和已有值提供搜索建议，也可手动输入新名称和值；移除列表展示所选笔记中已有的属性及包含该属性的笔记数量。
- **应用结果**：点击 **应用** 后显示已修改、无需修改和失败的数量；有失败时，再次应用只重试失败的笔记。

操作只修改 Markdown 笔记的 frontmatter，正文和其他属性保留。标签通过 **批量标签操作** 管理；同一属性不能同时设置和移除。

## 删除行为

删除卡片、批量选择或文件夹时，遵循 Obsidian **文件与链接** 中的删除偏好：系统回收站、仓库 `.trash` 文件夹或永久删除。Card Workspace 不提供独立回收站。
