description: 打开笔记、拖入编辑器、新建文件，以及使用右键和批量操作。

点击、右键和拖拽覆盖了大部分工作。设置只改变默认点击和拖放；菜单始终可以单独使用。

## 打开卡片

直接点击使用 **卡片默认打开方式**（默认 `smart`）：若有未固定的根编辑器标签页则复用，否则打开新标签页。其他选项是新标签页、右侧分栏和新窗口。

右键中的打开目标不受该设置影响。

## 拖入 Markdown 编辑器

只能把卡片拖入已打开的 **Markdown 编辑器**，并放到笔记中你想插入的位置。默认拖放是 **每次弹框确认**。也可以固定为插入 wiki link、嵌入 link、卡片内容，或标题加内容。

按卡片类型允许的拖放操作：

- Markdown — wiki、embed、content、title-content
- Base 和 canvas — wiki 和 embed
- Excalidraw — 仅 wiki

若操作不被支持，会提示：**此卡片类型不支持该拖拽插入操作。**

## 新建笔记

工具栏 **新建**（**创建笔记**）使用 **新建笔记内容**：

- **带 tags 属性**（默认）写入 `---\ntags:\n---`
- **完全空白** 写入空笔记

文件名基准为 **未命名**。在标签上右键选择 **新建带此标签的笔记**，会在当前文件夹新建笔记，并在 frontmatter 中写入该标签。

从文件夹树新建笔记、文件夹、白板或数据库时，总会进入该文件夹的浏览范围。若当前打开了卡片盒，这次新建会退出卡片盒。

## 导航栏菜单

在导航栏右键可以：

- **新建** — 笔记、文件夹、白板或数据库（包括库根目录）；**新建带此标签的笔记**
- **整理** — 重命名、创建副本、移动；复制库内路径或系统路径；在系统资源管理器中显示；**在文件夹中查找**（选中该文件夹并聚焦面板内搜索）；展开或折叠目录树；包含子文件夹
- **卡片盒** — **新建卡片盒…**、**将当前视图存为卡片盒…**、配置、创建副本、重命名、加入当前视图、恢复已移出的笔记、打开或退出卡片盒
- **收藏** — 加入或取消收藏；在同一类型内上移或下移；清空收藏
- **危险操作** — 删除文件夹；删除卡片盒（删除卡片盒不会删除笔记）

进入卡片盒后，标签条目的右键菜单会被隐藏。

## 卡片菜单

右键卡片可在当前窗口、新标签页、右侧分栏或新窗口打开；创建副本；移动、重命名或删除；加入或移出卡片盒；加入或取消收藏。

Markdown 卡片还可以复制标题、复制内容（当前 Markdown）、复制标题和内容，以及添加或移除标签。

## 批量操作

打开工具栏 **批量** 后，点击卡片可切换选中。Shift+点击会从上次选中的卡片起连选一段。

- 全选 / 清除选择
- 移动所选
- 为所选添加标签 / 移除所选标签
- **加入卡片盒**
- **移出卡片盒**（仅在打开卡片盒时）
- 删除所选
- 合并所选

**合并** 仅适用于 Markdown，且至少需要两篇笔记。合并对话框可设置合并后的标题、目标文件夹、来源顺序、分隔符（默认在笔记之间空一行）、是否保留或丢弃源笔记，以及实时预览。

## 删除

删除卡片、批量选择或文件夹时，使用 Obsidian **文件与链接** 中的删除偏好 — 系统回收站、库内 `.trash` 文件夹，或永久删除 — 而不是 Card Workspace 自己的回收站。
