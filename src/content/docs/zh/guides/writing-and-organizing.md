点击、右键菜单、批量模式和拖拽覆盖了大多数日常操作。设置只改变默认点击和拖放行为，明确的菜单操作始终可用。

## 打开卡片

直接点击使用 **卡片默认打开方式**。默认会尽量复用未固定的根编辑器标签页，否则打开新标签页。其他选择是新标签页、右侧分栏或新窗口，详见[设置](../reference/settings.md)。

从[双链导航](./linked-notes.md)打开卡片时，可以把来源笔记固定在 Card Workspace 中，一边检查上下文一边继续写作。开启 **双链卡片点击定位** 后，打开卡片还会跳到摘要对应的引用或搜索命中位置，详见[设置](../reference/settings.md)。

## 拖入 Markdown 编辑器

把卡片拖到已打开的 Markdown 编辑器中的具体位置。默认行为是 **每次弹框确认**。不同卡片类型允许：

- Markdown — wikilink、嵌入、正文或标题与正文
- Base、Canvas、图片、PDF、音频和视频 — wikilink 或嵌入
- Excalidraw 和其他文件 — 仅 wikilink

请求不支持的操作时，Obsidian 会显示 **此卡片类型不支持该拖拽插入操作。** 在手机和平板上，请改用卡片菜单中的插入和复制操作，详见[手机与平板](./mobile.md#插入与复制卡片内容)。

## 拖入 Canvas 或 Excalidraw

把卡片拖入已打开的 Canvas 或 Excalidraw 绘图，它会作为普通的 Obsidian 文件放入。展示方式和修饰键都由画布自己处理。即使处于批量模式，一次拖动也只包含起拖的那张卡片。

如果想把笔记拖到文件夹、标签、属性值或卡片盒上进行整理，请参阅[把卡片拖到导航](./navigation.md#把卡片拖到导航)。

## 按章节插入

[设置](../reference/settings.md#启用章节拖拽插入)中的 **启用章节拖拽插入** 默认关闭。开启后，拖入 Markdown 卡片时可以选择一个标题章节或整篇笔记。章节操作包括 **插入章节链接**、**插入章节内容** 和 **插入章节标题与内容**，并沿用当前的拖拽插入方式。

章节内容包含其下级标题，并在下一个同级或更高级标题处停止。插入的文字是原始 Markdown。标题元数据还在加载时，可以再次拖放这张卡片。如果 Obsidian 无法链接到某个标题，改为插入它的内容。

## 新建笔记与文件

工具栏的 **新建** 按钮会在当前文件夹（包括库根目录）中创建笔记，并把选中的标签和生效的属性筛选写入 frontmatter。在卡片盒中，笔记保存在该盒子的新建笔记文件夹中，并加入这个盒子；在双链来源中，笔记会放到上次浏览的文件夹。新笔记默认为空白；**新建笔记内容** 可以改为带一个空的 `tags` 属性。细节、模板和快速输入见[快速输入与模板](./quick-input-and-templates.md#新建笔记)。

从文件夹菜单可以在该文件夹中新建笔记、文件夹、白板、Excalidraw 文件或数据库。**新建 Excalidraw 文件** 需要 Excalidraw 插件；它会创建 `.excalidraw.md` 绘图，并直接在 Excalidraw 中打开。标签菜单可以在当前文件夹新建已经带有该标签的笔记。从卡片盒中使用文件夹新建操作时，会切回对应的文件夹来源。

## 导航与卡片菜单

导航菜单覆盖新建、重命名、创建副本、移动、复制路径、在系统资源管理器中显示、收藏、展开树、调整分区、筛选和[卡片盒](./card-boxes.md)操作。重命名或删除标签时，确认后会同步更新或移除笔记、活动筛选、收藏和卡片盒规则中的引用。

卡片菜单可以选择打开位置；复制、移动、重命名或删除文件；管理收藏和卡片盒成员；更改卡片的 **背景颜色** 或图标；Markdown 卡片还可以复制内容，或打开 **添加/删除标签...** 和 **添加/删除属性...**。这两个操作使用与批量模式相同的对话框，只作用于这一篇笔记。完整清单见[命令与菜单](../reference/commands-and-menus.md)。

复制 Markdown 内容时会跳过顶部 frontmatter，得到正文；文件副本仍保留原始文件内容。

## 批量模式

打开 **批量**，点击卡片即可切换选中；Shift+点击从上次选中的卡片开始连选。

- 全选或清除选择
- 移动所选笔记
- 添加或移除标签
- 批量设置或移除 Markdown 笔记的属性
- 加入卡片盒，或从当前卡片盒移出
- 为所选卡片设置背景颜色
- 删除所选笔记
- 合并所选 Markdown 笔记

也可以把任意一张已选卡片拖到导航中的文件夹、标签、属性值或卡片盒上，对整组可见选择执行相应操作。

合并至少需要两篇 Markdown。对话框可以设置标题、目标文件夹、来源顺序，并提供实时预览。分隔符默认为 **空行**，也可以改为 **分隔线** 或 **仅换行**。**合并后将源笔记移入废纸篓** 默认关闭，源笔记会留在仓库里；开启后，移入废纸篓会遵循 Obsidian 的删除偏好。只有第一篇来源笔记的 frontmatter 会保留在合并结果顶部；其他来源的 frontmatter 不会合并进去。

### 批量标签操作

在批量模式中选中 Markdown 笔记，点击工具栏的 **批量标签操作**。对话框会显示本次作用的笔记数量。一次操作可以同时添加和移除标签。移除父标签时也会移除它的子标签，并且先执行移除、再执行添加。点击 **应用** 后显示已修改、无需修改和失败的数量；有失败时，再次应用只重试失败的笔记。单张卡片的 **添加/删除标签...** 会为这一篇笔记打开同一个对话框。

### 批量属性操作

在批量模式中选中 Markdown 笔记，点击工具栏的 **批量属性操作**。对话框会显示本次作用的笔记数量；可在一次操作中设置多个属性，并移除其他不再需要的属性。

- **设置属性**：填写属性名、类型和值，为所选笔记创建属性或覆盖已有值。例如，将一组笔记的 `status` 统一设为 `review`。
- **类型与值**：支持文本、列表、数字、复选框、日期和日期时间；列表项支持文本或数字，设置列表时会替换原有列表。
- **输入建议**：属性名和已有值提供搜索建议，也可手动输入新名称和值；移除列表展示所选笔记中已有的属性及包含该属性的笔记数量。
- **应用结果**：点击 **应用** 后显示已修改、无需修改和失败的数量；有失败时，再次应用只重试失败的笔记。

操作只修改 Markdown 笔记的 frontmatter，正文和其他属性保留。同一属性不能同时设置和移除。单张卡片的 **添加/删除属性...** 会为这一篇笔记打开同一个对话框。标签通过 **批量标签操作** 管理。

## 删除行为

删除卡片、批量选择或文件夹时，遵循 Obsidian **文件与链接** 中的删除偏好：系统回收站、仓库 `.trash` 文件夹或永久删除。Card Workspace 不提供独立回收站。
