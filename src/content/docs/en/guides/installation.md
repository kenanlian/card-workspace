Install Card Workspace from inside Obsidian, in the community plugin browser. Manual installation from GitHub Releases stays available if you need a specific version.

## Requirements

- Desktop Obsidian (not mobile)
- Obsidian **1.9.0** or later
- The plugin UI follows Obsidian’s language (`zh*` → Simplified Chinese, otherwise English)

## Install from community plugins

1. Open Obsidian **Settings → Community plugins**.
2. Turn off Restricted mode (also called Safe mode) if it is on.
3. Select **Browse**, then search for **Card Workspace**.
4. Select **Install**, then **Enable**.

The plugin’s [directory page](https://community.obsidian.md/plugins/card-workspace) lists the same entry and can hand the install off to Obsidian.

## Install manually from GitHub Releases

Use this when you need a version other than the current one.

1. Download the release you want from the [Releases](https://github.com/kenanlian/obsidian-card-workspace/releases) page.
2. Extract the archive and copy `main.js`, `manifest.json`, and `styles.css` into:

   `<vault>/.obsidian/plugins/card-workspace/`

3. Open Obsidian **Settings → Community plugins**.
4. Turn off Restricted mode (also called Safe mode) if it is on.
5. Enable **Card Workspace** in the installed plugin list.

## Next step

After the plugin is enabled, [open the view and browse your first cards](/card-workspace-site/en/guides/getting-started/).
