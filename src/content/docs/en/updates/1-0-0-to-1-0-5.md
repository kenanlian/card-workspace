This group covers the foundation of the sidebar workflow: choose a source, scan cards, and save a useful view.

The page reserves the **1.0.0–1.0.5** range. Only **1.0.0, 1.0.1, and 1.0.2** were published; there are no tags or Releases for 1.0.3–1.0.5, so no features are assigned to those versions. The next group starts at the published [1.1.2](./1-1-2-to-1-1-6.md).

## Independent two-column navigation

1.0.0 introduced the plugin’s own folder, tag, and card-box navigation beside cards with titles and excerpts. Narrow sidebars switch to a single pane, the navigation column can be resized, and the ribbon or command palette opens the workspace without File Explorer linking.

Optional counts, count tooltips, and common folder and note actions are available in navigation. See [Navigation](../guides/navigation.md) and [Commands and menus](../reference/commands-and-menus.md).

## Save collections and frequent destinations

Card boxes save folder and tag views, with notes that can be manually added or removed. Favorite folders, notes, tags, and boxes provide shortcuts in navigation.

See [Card boxes](../guides/card-boxes.md) and [Favorites in navigation](../guides/navigation.md). Later releases added property rules, grouping, and mixed favorite ordering.

## Search, create, and organize notes

Local search, pins, and virtualized scrolling support everyday scanning. This series strengthened search-index persistence, vault-root path handling, and tag filtering. Newly created notes open in a new tab, and bulk merge provides destination controls and a preview.

See [Browsing cards](../guides/browsing-cards.md) and [Writing and organizing](../guides/writing-and-organizing.md).
