This group covers six published releases: **1.3.5, 1.3.6, 1.4.0, 1.4.1, 1.4.2, and 1.4.3**. The current guides describe **Card Workspace 1.4.3**.

## Shape the navigation column

1.4.0 lets you drag folders in the navigation column. Drop on the middle of a row to move a folder into it, or on the top or bottom quarter to reorder siblings. 1.4.1 adds **Sort child folders by name (A → Z)**, **(Z → A)**, and **Manual sorting**. A reorder drop switches that sibling group to manual order.

1.4.1 also hides folders, tags, and the six navigation sections. Restore them under **Settings → Card Workspace → Navigation**. Hiding changes the navigation column only. 1.4.2 adds the same name or manual order for tags, subtags, and property values, and **Reveal active note's folder** on the Folders menu.

See [Hide navigation entries](../guides/navigation.md#hide-navigation-entries) and [Arrange folders, tags, and properties](../guides/navigation.md#arrange-folders-tags-and-properties).

## Search hits, history, and link references

1.3.6 shows search matches as separate two-line snippets, up to a count you choose in settings (default 2, maximum 5). 1.4.3 keeps the lightweight list, task, heading, code, and link cues inside those snippets. Click a snippet, or press Enter or Space, to open that hit in the note’s current editing or reading mode.

1.4.2 remembers the 30 most recent queries across card views and suggests up to six matches. 1.4.3 presents that history with Obsidian’s suggestion list. Closing search or clearing the query stores the current text first.

1.3.6 also sorts outgoing links and backlinks by reference count, highest first, and shows several backlink contexts on one card. The default is three; settings can choose 1, 2, 3, or all, and each card can expand the rest.

See [Search](../guides/browsing-cards.md#search), [Linked notes](../guides/linked-notes.md), and [Settings](../reference/settings.md).

## Compact cards, hover size, and section drops

1.4.1 lets **Preview lines** go down to 0, which hides the ordinary excerpt, and keeps the two-column layout until the card column would be narrower than 160 CSS pixels.

1.4.3 adds **Card hover preview width** and **Card hover preview height** (defaults 600 × 400). They apply when the Page preview core plugin is enabled and shrink to fit the window.

1.3.6 adds **Enable section drag insertion**, off by default. With it on, a Markdown drop can target a heading section or the whole note.

See [Browsing cards](../guides/browsing-cards.md), [Hover preview](../guides/browsing-cards.md#hover-preview-and-editor-sync), and [Insert a heading section](../guides/writing-and-organizing.md#insert-a-heading-section).

## Boxes, merge, and metadata

1.3.5 gives the merge dialog separator presets — **Blank line**, **Horizontal rule**, and **Line break** — and **Trash source notes after merge**, which is off by default. 1.4.2 stores each card box’s grouping and edits it from **Configure card box…**. Saving a folder view copies the grouping in effect at that moment.

1.4.3 uses one dialog for tags and another for properties, from a Markdown card menu or from bulk mode. A card menu’s **Add/remove tags...** and **Add/remove properties...** apply to that note; the toolbar actions apply to the selection.

See [Card boxes](../guides/card-boxes.md) and [Writing and organizing](../guides/writing-and-organizing.md).

## Settings layout and Obsidian versions

1.3.5 organizes preferences into **Behavior** and **Appearance**, hides **Image fit** while card images are off, and rebuilds forms on native confirmation dialogs. That release required Obsidian 1.13.0. 1.3.6 lowers the requirement to Obsidian **1.11.4**. 1.4.0 keeps 1.13-only settings search and native dialogs behind a version check, so 1.11.4–1.12 continue to use the compatible dialogs and the same settings.

1.4.1 adds the **Navigation** settings group for hidden sections, folders, and tags. Vaults on Obsidian older than 1.11.4 stay on 1.3.4, the last release those versions can run.

1.4.3 licenses the plugin as GPL-3.0-only. Releases through 1.4.2 keep the MIT License they were published under. See [Limits and privacy](../reference/limits-and-privacy.md).
