This group covers ten releases: **1.4.4, 1.4.5, 1.4.6, 1.4.7, 1.4.8, 1.4.9, 1.4.10, 1.5.1, 1.5.2, and 1.5.3**. There is no 1.5.0. The current guides describe **Card Workspace 1.5.3**.

## Capture with quick input and templates

1.4.7 adds the **Templates** navigation section and quick input. 1.4.8 moves quick input into independent desktop windows that stay on top by default, adds Obsidian’s Properties editor to drafts, and supports inline formats such as `{{date:YYYY-MM-DD}}` in templates. 1.4.9 lets you register an existing Markdown file with **Set as template**.

1.4.10 separates quick input from templates and adds title, folder, card-box, tag, and property controls to each draft, with a rule for titles that already exist: ask, append, or create a numbered note. The toolbar **New** button also works inside card boxes and adds the new note to the box.

See [Quick input and templates](../guides/quick-input-and-templates.md).

## Phones and tablets

1.5.1 runs on Android and iOS/iPadOS. Phones show one card column with navigation in a dialog; tablets adapt to the available width. Card menus can insert or copy content into the note you were editing, and source changes follow Obsidian’s back and forward history. Display preferences are stored per device.

1.5.2 shows the current source in the phone’s page header, hides the header and toolbar while you scroll when Auto full screen is on, and keeps phone navigation rows compact.

See [Phones and tablets](../guides/mobile.md).

## More file types and diagram previews

1.4.4 draws Canvas files as small diagrams and shows Excalidraw drawings through their exported SVG; 1.4.5 and 1.4.6 clean those SVG previews and remove the drawing background. 1.4.7 opens drawings made with **New Excalidraw file** directly in Excalidraw.

1.4.10 adds **Show file types** — documents only, common formats, or all formats — so images, PDFs, audio, video, and other files can appear as cards. Image thumbnails now also support AVIF, GIF, and SVG. 1.4.9 lets you drag a card into Canvas or Excalidraw as a native file.

See [File types](../guides/browsing-cards.md#file-types) and [Diagram previews](../guides/browsing-cards.md#diagram-previews).

## Card styles, colors, and icons

1.4.7 adds **Font size**, **Density**, and **Card style**: default cards, minimal outline, list, flat, or accent bar. 1.5.1 adds eight theme-adaptive card background colors, set as a default, per card, or for a bulk selection, and custom icons: any Lucide icon, an emoji from the full offline catalogue, or no icon, for navigation entries and cards, with defaults per category.

See [Appearance and icons](../guides/appearance.md).

## Organize by dragging and filter card boxes

1.5.2 lets you drop cards onto a folder to move them, a tag to add it, a property value to set it, or a card box to add them; dragging a selected card applies to the whole selection. Tag and property filters now narrow card boxes as well as folders, without changing the box’s rules or members. The navigation header gains an **Expand all** / **Collapse all** button, and the Tags section lists every tag in the vault.

See [Drag cards onto navigation](../guides/navigation.md#drag-cards-onto-navigation) and [Card boxes](../guides/card-boxes.md#filters-and-startup-behavior).

## Settings pages

1.5.3 splits the settings tab into seven pages: **Interface appearance**, **Cards and previews**, **Navigation**, **Opening and dragging**, **New notes and templates**, **Quick input**, and **Default icons**. Settings keep their values. See [Settings](../reference/settings.md).
