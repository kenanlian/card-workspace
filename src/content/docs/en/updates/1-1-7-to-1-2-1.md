This group contains **1.1.7, 1.1.8, 1.1.9, 1.2.0, and 1.2.1**, extending card browsing from folders to metadata and note connections.

## Refine folder views with properties

1.1.9 added property navigation and filtering. Choose visible frontmatter keys, then browse their values: values within one property use OR, while different properties use AND. Property clauses can also become card-box rules so membership follows metadata changes.

See [Property filters](../guides/property-filters.md) and [Card boxes](../guides/card-boxes.md).

## Unified arrangement and tag maintenance

1.1.9 brought sorting and grouping into the toolbar menu. Organize cards by folder, tag, task status, or card-box rule, and choose a group order. Navigation trees gained expand-all and collapse-all actions, and favorites gained manual ordering.

Confirmed tag renames or deletions update references in notes, active filters, favorites, and card-box rules.

See [Browsing cards](../guides/browsing-cards.md), [Navigation](../guides/navigation.md), and [Writing and organizing](../guides/writing-and-organizing.md).

## Outgoing links and backlinks as card sources

1.2.0 added the **Links** navigation section. Outgoing links and backlinks can follow the active note or stay pinned while you inspect other notes. The visible result can also be saved as a card-box snapshot.

A snapshot stores manually added members and does not change automatically with the link graph. See [Linked notes](../guides/linked-notes.md) for the workflow.
