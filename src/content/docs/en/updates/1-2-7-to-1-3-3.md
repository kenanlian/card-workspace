This group covers **1.2.7, 1.2.8, 1.2.9, 1.3.0, 1.3.2, and 1.3.3**. **1.3.1** also has a version tag; its changes shipped in 1.3.2 without a separate public Release. The current guides describe **Card Workspace 1.3.4**; see [Card images](./1-3-4.md) for the latest update.

## Switch between tag and property filters

1.2.7 corrected browse-filter switching: activating tags clears property filters, and activating properties clears tag filters. Conditions within the same filter type can still be added, and search can further narrow the result. Navigation-search styling and list scrollbars also improved.

See [Browsing cards](../guides/browsing-cards.md) and [Property filters](../guides/property-filters.md). Use [Card-box rules](../guides/card-boxes.md) to preserve different tag and property views.

## Property groups and sticky headers

1.2.8 added **Property** grouping: enable a property in navigation, then choose it in Sort & group. The complete property-value set determines each group; notes without supported values enter Unassigned. Grouping also works in card boxes and linked-note sources.

1.2.8–1.2.9 refined headers to show the dimension, values, and counts. 1.2.9 keeps the current group’s header at the top of the card stream while scrolling through it.

See [Property grouping](../guides/property-filters.md) and [Sorting and grouping](../guides/browsing-cards.md).

## Excerpts show relevant context

1.3.0 made search excerpts start near body matches. Link cards prefer reference context: backlinks show the paragraph linking to the source, and outgoing links with headings or block references preview the target location. An active search takes priority.

The new **Jump to link location when opening a link card** setting is off by default. Enable it to open a linked-note card at its preview location; missing locations fall back to opening normally.

See [Search context](../guides/browsing-cards.md), [Linked notes](../guides/linked-notes.md), and [The location setting](../reference/settings.md).

## Lists, tasks, and compatibility

1.3.0 preserved link text, list markers, and task checkboxes in excerpts and fixed duplicate scrolling. 1.3.3 further aligned task checkboxes, list text, and file icons.

1.3.1’s compatibility changes shipped with 1.3.2: index and location work use main-window timers, and Obsidian 1.13 or later can search the plugin’s settings. 1.3.2 also adjusted search-performance tooling rather than adding a new user control.

See [Card previews](../guides/browsing-cards.md) and [Settings](../reference/settings.md).
